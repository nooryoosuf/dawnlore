# Land of Dawn — Cinematic MLBB Lore Story Library

A premium, responsive storytelling web experience for Mobile Legends: Bang Bang, blending the content discovery patterns of Netflix with the typography and editorial reading quality of a digital book platform.

Built with **React 18**, **TypeScript**, **Tailwind CSS**, and **Vite**, powered strictly by the canonical Land of Dawn lore dataset.

---

## 🌟 Key Features

1. **Netflix-Style Cinematic Billboard:**
   - Full-bleed hero visuals with layered atmospheric gradients and character silhouette art.
   - Highlights the core Moniyan and Abyssal conflicts with instant "Begin Reading" and character inspection.
   - Ambient Web Audio synthesizer drone providing immersive fantasy atmosphere with zero external audio dependencies.

2. **The Sovereign Canon (Story Showcase):**
   - Five complete canonical narrative arcs:
     - *Act I: The Prince of Darkness and the Lost Heir* (Aurelius II / Silvanna & Dyrroth)
     - *Act II: A Hunter Born of Treachery* (Alucard & the Monastery of Light)
     - *Act III: The Ruin of the Iron Hammer* (Terizla & Julian)
     - *Act IV: The Siege of the Imperial Sanctuary* (Climactic battle for the capital)
     - *Act V: The Midnight Rebirth of Aberleen* (Carmilla & Cecilion gothic blood covenant)
   - Reading progress, word count, estimated reading time, chapter indicators, and bookmarking.

3. **Immersive Digital Book Reader:**
   - Fullscreen distraction-free reading mode.
   - Typography controls: Cormorant Garamond serif vs. Inter clean sans.
   - 4-level font scale adjustments (A- / A+).
   - Table of Contents sidebar with one-click chapter navigation and chapter summaries.
   - Editorial drop-caps, chapter metrics, and character mentions with quick-lookup drawers.
   - Archival epilogues and next-arc progression.

4. **Champions of Dawn Codex:**
   - 10 heroes across the Moniyan Empire, Lightborn Order, Abyssal Host, Demon Hunters, and Blood Demons.
   - High-resolution portraits and transparent renders sourced from verified official CDNs.
   - Character dossiers displaying canonical roles, quotes, faction allegiances, and verified canonical relationships.

5. **Chronology of Dawn (Timeline Visualizer):**
   - 9 historical milestones with approximate periods and confidence ratings.
   - Visual causal linkages (`connection_to_adjacent`) explaining how each historical event provoked subsequent conflicts.

6. **The Realm Factions:**
   - In-depth dossiers on the Moniyan Imperial Court, Lightborn Order, The Abyssal Host, Order of Demon Hunters, Blood Demon Enclave, and Provincial Aristocracy.

7. **Universal Command Search (`Ctrl+K`):**
   - Instant search across stories, chapters, heroes, timeline events, and factions.

---

## 🚀 Running the Project

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```

The application runs on `http://localhost:3000`.
